# Hermes 국내주식 투자 리서치 비서 요구사항

상태: 사용자 인터뷰 승인됨

## 범위

- 국내 KOSPI·KOSDAQ 보통주와 일반 ETF만 다룬다.
- 우선주, SPAC, KONEX, ETN, 레버리지·인버스 ETF는 제외한다.
- 후보 자동 발굴과 사용자가 지정한 종목의 심층 분석을 모두 제공한다.
- 후보는 기본 5개이며 오전 08:30, 평일 20:00, 토요일 12:00 KST 보고를 목표로 한다.
- 주식 주문은 사용자가 직접 수행하며 시스템은 실제 주문을 실행하지 않는다.

## 판단

- 최신 연간·TTM 영업이익 양수와 일반기업 OCF 양수를 필수로 본다.
- FCF는 필수 배제가 아니라 원인 분석과 가점·경고에 사용한다.
- 매출채권·재고자산 회전율 유지 또는 상승을 선호한다.
- CB·BW·유상증자는 존재만으로 배제하지 않고 희석 규모, 목적과 반복성을 본다.
- 확인된 횡령·배임·중대한 지배구조 위험은 제외 또는 매수 보류 근거다.
- 실적과 계약을 핵심 재료로 보며 비공식 정보는 공식 사실과 연결될 때까지만 다룬다.
- 의심 종목을 숨기거나 `작전주`로 단정하지 않고 근거와 강한 경고를 함께 보여준다.
- 매수 보류 조건과 추가 확인 조건을 항상 명시한다.

## 포트폴리오

- 미래에셋증권과 토스증권 입력을 하나의 포트폴리오로 합치되 broker 원장은 보존한다.
- 매수 이유, 확인된 사실, 가정, 무효화 조건을 대화로 정리하고 승인 후 저장한다.
- 추가매수는 손실률만으로 제안하지 않고 최초 논리, 재무, 재료와 가격 조건을 다시 검증한다.
- 보유, 부분매도 검토와 전량매도 검토 시나리오를 함께 제시한다.

## 채널과 기록

- Oracle을 상시 실행 기준점으로 두고 Desktop과 Telegram이 같은 task/report ID를 사용한다.
- Desktop은 상세 분석과 멀티에이전트 검증, Telegram은 모바일 지시·요약·알림에 사용한다.
- 일일 후보는 전용 DB에 저장하고 승인된 실제 매매와 주간 보고서만 개인 WIKI에 쓴다.
- 사실, 추론, 가정, 확인 불가를 분리한다.

## 검증과 변경 통제

- point-in-time 백테스트와 지속 모의운용을 사용한다.
- 수수료와 미래정보 누수를 반영한다.
- 이수페타시스를 최초 수동 사례로 검증한다.
- 규칙 변경은 비교 결과와 사용자 승인을 요구한다.
- 수익률은 목표이며 보장하지 않는다.
